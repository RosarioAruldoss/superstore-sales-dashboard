# Superstore Sales Dashboard

This project analyzes sales data from the Superstore dataset to uncover key business insights.  
The analysis was done using Python (Pandas, Matplotlib, Seaborn) in a Jupyter Notebook.

## 📂 Dataset

Superstore Sales dataset from Kaggle  
Includes order details, product categories, region, and customer data.

## 🛠️ Tools Used

- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook

## 📊 Key Insights

- Highest sales category is `Category Name`
- Top sub-category is `Sub-Category Name`
- Region contributing most to sales is `Region Name`
- Top-performing state is `State Name`

## ✅ Conclusion

Business recommendations:
- Focus promotions on high-performing regions & categories
- Improve strategies in lower-performing regions

## 📎 How to Run

1. Clone repository  
2. Open `superstore_sales_dashboard.ipynb` in Jupyter  
3. Run all cells
